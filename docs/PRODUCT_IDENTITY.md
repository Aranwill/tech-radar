# Product Identity — Dalil

## Nombre

**Dalil**

Árabe: **دليل**

Transliteración: **Dalīl** / **Dalil**

## Sentido

En árabe, `دليل` puede usarse con sentidos relacionados con guía, indicio, evidencia o prueba según el contexto.

Para el producto adoptamos deliberadamente esta combinación conceptual:

- **guía:** ayuda a orientarse entre grandes volúmenes de información;
- **indicio/señal:** detecta cambios, repositorios, investigaciones y tendencias relevantes;
- **evidencia:** mantiene procedencia y fuente original visibles.

Dalil no pretende reemplazar la fuente ni presentar una “verdad automática”. Organiza señales, contexto y evidencia para que el usuario pueda explorar y decidir qué merece atención.

## Tagline

**Inteligencia tecnológica.**

El tagline visible actual acompaña la identidad Dalil y puede evolucionar con evidencia de uso, pero la idea de producto permanece:

> descubrir señal útil, conservar trazabilidad y facilitar el acceso a la evidencia original.

## Identidad visual candidata

La identidad visual en evaluación usa:

- dark mode con fondo azul-negro profundo;
- azul eléctrico/neón como acento principal;
- light mode con fondo ostra/crema suave en lugar de blanco puro;
- superficies sobrias y alto contraste;
- iconografía local y minimalista;
- visualizaciones pequeñas sólo cuando aportan información.

La paleta exacta todavía es candidata y requiere revisión visual en desktop/mobile antes de quedar congelada.

## Alcance técnico del nombre

Esta decisión fija el **nombre de producto**.

No implica automáticamente renombrar:

- el repositorio `tech-radar`;
- el package name;
- ramas históricas;
- variables internas;
- URLs o deployment.

Esas migraciones, si se consideran útiles, deben hacerse como cambios técnicos separados y revisables.
